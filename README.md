# 藍圖思維（三元科技）產品架構分析：以 ERP 為核心的層級拆解

本報告針對 **三元科技有限公司（SUN MOON TECHNOLOGY CO., LTD. / 藍圖思維 ACTGSYS）** 之產品生態，釐清其演進脈絡，並以其最本質的 **ERP（進銷存與單據流轉）** 功能為核心，將各項產品與 AI 模組按照「核心至外圍」進行層級拆分。

---

## 一、 背景與演進脈絡（原貌 vs 現狀）

1. **起家原貌（硬體階段）**：三元科技最早以**電子電路設計**起家。
2. **軟體起點（接案階段）**：成立「藍圖思維」品牌後，最初切入軟體的形式是**傳統客製化系統接案（SI）**，為企業量身打造 ERP 與 CRM。
3. **橫向擴張（標準化 SaaS + AI 包裝）**：將多年接案累積的模組標準化，搭上大語言模型（LLM）與 Agentic RAG 熱潮，拆分成多款 SaaS 與 LINE 應用對外銷售。
4. **最少核心本質**：剝離所有 AI 包裝與對話入口後，其最根本的基石依然是**「中小企業的客製化進銷存與單據管理系統（傳統 ERP）」**。

---

## 二、 產品層級拆解（圍繞 ERP 核心）

```
[ 第四層：外圍增強層 (AI Wrapper) ]
  ├── 發票 OCR 辨識 / 名片掃描 / BOM 表比價
  └── 跨部門 AI 數據洞察 / 企業 RAG 知識庫
          │
[ 第三層：外圍通路層 (Channel & UI) ]
  ├── LINE Bot 智能下單
  ├── LINE Bot 智能客服
  └── LINE Bot 智能打卡
          │
[ 第二層：次核心層 (Extended Core) ]
  ├── 前段業務：DanLee CRM (商機、名片、報價、合約)
  └── 後段會計：TanJee 記帳系統 (憑證、傳票、損益表、資產負債表)
          │
[ 第一層：核心層 (Core Engine) ]
  └── Dinkoko ERP (進銷存、採購、多倉庫存、單據對帳、發票)
```

---

### 第一層：核心層（Core Engine：營運與交易運轉的心臟）
直接掌管實體物品與交易單據的生命週期。沒有這一層，其餘所有模組皆無資料依託：
* **Dinkoko ERP**：
  * **採購與庫存**：多倉庫存管理、採購進貨、庫存調撥與盤點。
  * **銷售出貨**：接單出貨扣庫、發票開立、單據自動對帳。
  * **營運基礎**：全流程單據串聯，避免跨部門資訊落差與人工重工。

---

### 第二層：次核心層（Extended Core：前導商機與後續財務）
緊密依附於 ERP 前後，負責「把單接進 ERP」與「承接 ERP 衍生的金流帳務」：
* **前段業務｜DanLee CRM**：
  * 搜集潛在客戶名單、業務商機追蹤、智能產出報價單與合約檢視。
  * 角色：負責開拓商機，成交後轉化為 ERP 訂單。
* **後段會計｜TanJee 記帳系統**：
  * 接收 ERP 出貨與採購單據，自動生成會計傳票與收支紀錄。
  * 產生損益表、資產負債表，提供成本追蹤與多幣別支援。
  * 角色：將 ERP 的交易事實沉澱為標準財務報表。

---

### 第三層：外圍通路層（Channel & UI：輕量互動入口）
將 ERP/CRM 的複雜表單操作對話化、輕量化，降低使用者與終端消費者的操作門檻：
* **LINE Bot 智能下單**：顧客直接在 LINE 點選下單，系統自動寫入 ERP 訂單排程。
* **LINE Bot 智能客服**：串接常見問題與內部系統，由 AI/自動化回覆處理日常諮詢。
* **LINE Bot 智能打卡**：員工上下班打卡通道，屬於輕量人資管理入口。

---

### 第四層：外圍增強層（AI Wrapper：自動化與分析外掛）
依附於現有流程上的增效工具與商業包裝，本身無法單獨成為獨立運作的業務系統：
* **流程自動化輸入（Data Intake）**：
  * **發票 OCR 辨識**：加速單據進 ERP 的鍵入速度。
  * **AI 名片掃描**：加速聯絡人進 CRM 的建檔速度。
  * **BOM 表比價自動化**：輔助採購人員多通路搜尋比價。
* **決策與知識檢索（Analytics & RAG）**：
  * **AI 智能商業洞察**：基於 ERP/CRM 累積的營運歷史數據，分析銷售機會與庫存配置策略。
  * **企業 RAG 知識庫助手**：內部 SOP 與文檔檢索問答。

---

## 三、 總結判定

* **實質本體**：傳統的製造/貿易/批發業**進銷存（ERP）與記帳軟體**。
* **包裝手法**：以 **LINE 對話介面** 當作前端操作皮囊，輔以 **OCR 與 LLM 分析** 作為 AI 賦能的行銷賣點，將傳統專案接案程式碼重組成標準化 SaaS 套件。

## 四、 快速啟動 Web 管理後台 (Quick Start Web GUI)

本專案提供內建零構建（Zero-Build SSR）的企業級營運後台，採用 FastAPI + Jinja2 + HTMX + Tailwind CSS：

### 1. 啟動伺服器
於專案根目錄執行以下指令：
```powershell
python -m uvicorn src.channel_ui.web.app:app --reload --port 8000
```

### 2. 訪問頁面
啟動後使用瀏覽器開啟：
* **營運儀表板**：[http://127.0.0.1:8000/](http://127.0.0.1:8000/)（KPI 圖卡、安全存量警報、近期單據）
* **訂單與出貨管理**：[http://127.0.0.1:8000/orders](http://127.0.0.1:8000/orders)（HTMX 一鍵鎖庫、出貨扣庫、發票開立、物流與發票 PDF 下載）
* **多倉庫存與流水**：[http://127.0.0.1:8000/inventory](http://127.0.0.1:8000/inventory)（主倉與門市倉存量、原子性調撥作業、雙記帳流水）
* **API 互動規格文件**：[http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)（OpenAPI / Swagger UI）
